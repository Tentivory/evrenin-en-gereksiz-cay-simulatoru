# Evrenin En Gereksiz Çay Simülatörü

## Bu Ne?

Bu, çay demlemeyi simüle eden dünyanın en ciddi, en bilimsel ve aynı zamanda en absürt yazılımıdır. Gerçekten çalışır. Gerçekten. Sadece çay demlemez. Ama demler gibi yapar. Ve bu çok önemlidir.

### Özellikler
- Sonsuz (aslında 5-6 saniye) bekleme süresi
- Rastgele felsefi krizler
- Çayın duygusal durumunu analiz etme
- Gerçek çaydan daha az kalorili

### Kurulum
```bash
python cay_demle.py
```

### Uyarı
Bu yazılım çay içmenizi sağlamaz. Hatta çay içme isteğinizi yok edebilir. Sorumluluk kabul etmiyoruz.

### Neden Var?
Çünkü olması gerekiyordu. Veya gerekmiyordu. Ama artık var.
